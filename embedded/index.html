4-Channel Live Sensor Scope & Noise Filter

Project Overview

Technology: ADC (Analog‑to‑Digital Conversion)

Hardware: ESP32, analog joystick, photoresistor, NTC temperature sensor, potentiometer.

Key Features

  • Five analog input channels.
  • Calibrated millivolt readings using analogReadMilliVolts().
  • Rolling‑average noise filtering.
  • Joystick dead‑zone handling.
  • Live Serial Plotter output for real‑time monitoring.

ADC Technology Deep Dive

The ESP32’s built‑in SAR ADC samples each analog input at up to 6 kS/s with 12‑bit resolution. By scaling the raw counts with the reference voltage and the chosen attenuation, the analogReadMilliVolts() helper returns a calibrated millivolt value, simplifying downstream calculations. The rolling‑average filter smooths high‑frequency noise while preserving rapid changes, which is critical for joystick positioning and light‑sensor responsiveness. Attenuation settings are configured per‑channel to match each sensor’s voltage range, ensuring optimal signal‑to‑noise ratio.
